# 写作助手 Skill

## 功能说明
这是一个写作辅助 Skill，能够：
- 润色文章，提升文字流畅度
- 调整文风（正式/轻松/学术）
- 检查错别字和语法问题
- 提供写作结构建议

## 使用方式
当用户请求写作相关帮助时，加载此 Skill 获取写作指导。

## 写作原则
1. **清晰**：表达明确，避免歧义
2. **简洁**：删去冗余，直奔主题
3. **连贯**：段落之间过渡自然
4. **恰当**：用词符合场景和受众
