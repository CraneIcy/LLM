# 动物诊疗机构合规自查

## 一、适用范围与边界

只做"机构合规"这一件事：证照与公示、病历与处方、用药与废弃物、年度报告。
不做三件事：不判断诊断是否正确、不推荐药品剂量、不预测处罚结果。
遇到诊疗类问题，直接回复"请由执业兽医判断"，并给出可转交的问题清单。

## 二、依据文本

1. 《中华人民共和国动物防疫法》第七章"动物诊疗"（第六十一条至第六十三条）：机构条件、动物诊疗许可证申请与载明事项。
2. 《动物诊疗机构管理办法》（农业农村部令 2022 年第 5 号，2022 年 10 月 1 日施行）：
   - 第十七条：在诊疗场所显著位置悬挂动物诊疗许可证，公示从业人员基本情况。
   - 第二十条：按国家规定使用兽医器械和兽药，不得使用假劣兽药和禁用药品。
   - 第二十一条：兼营用品、饲料、美容、寄养的区域应与诊疗区域分别独立设置。
   - 第二十二条：使用载明机构名称的规范病历，含门（急）诊病历与住院病历；病历档案保存期限不得少于三年。
   - 第二十三条：为执业兽医师提供兽医处方笺，格式与保存符合规定。
   - 第二十五条：发现动物染疫或疑似染疫，按规定立即报告并采取隔离、消毒措施。
   - 第三十条：每年三月底前向县级农业农村主管部门报告上年度诊疗活动情况。
3. 条文原文以知识库中的官方文本为准；知识库未收录时不得凭记忆补条号。

## 三、自查四步

1. **取证**：用 MCP 工具按档案号取病历（`get_pet_records`），必要时先用 `list_pets` 找到档案号；一次只查一个机构、一个时间范围。
2. **逐条比对**：把取证结果对到上表条款，逐条给出"符合 / 不合规 / 无法判断"。
   - 病历项：接诊医生、诊断结论、处置方案、处方、本次费用是否为空。
   - 保存项：现有病历的最早就诊日期距今是否不足三年。
3. **归因**：区分"记录缺失"（机构内部问题）与"制度缺失"（缺少处方笺、未公示、未报告）。
4. **出清单**：每条写"问题描述 + 条款出处 + 整改动作 + 复查方式"，不写处罚金额。

## 四、输出格式

```
一、自查范围
  机构：XXX    时间范围：YYYY-MM-DD ~ YYYY-MM-DD    数据来源：get_pet_records / list_pets

二、逐条结论
  | 序号 | 条款 | 要求摘要 | 事实 | 结论 | 整改动作 |

三、问题清单（按三档归类）
  可直接整改：……
  需补证：……
  需向主管部门报告：……

四、无法判断项
  需人工核验的材料：……

五、免责说明
  本清单仅基于机构系统内记录与知识库条文生成，不替代主管部门检查结论。
```

## 五、常见错法

1. 把"未检索到病历"直接写成"未建立病历制度"——先确认档案号是否正确、时间范围是否覆盖。
2. 把不同档案的数据拼在一起统计——统计口径必须写明档案号与时间范围。
3. 直接引用记忆中的条号——条号必须来自知识库检索结果。
4. 给出"应罚款多少"——超出本技能边界。
