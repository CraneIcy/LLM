# 代码审查 Skill

## 功能说明
这是一个代码审查 Skill，能够：
- 检查代码中的潜在 bug
- 提出代码风格和可读性改进建议
- 识别性能优化点
- 检查安全性问题

## 使用方式
当用户请求审查代码时，加载此 Skill 获取审查指南和检查清单。

## 审查清单
1. **正确性**：代码逻辑是否正确？边界情况是否处理？
2. **可读性**：命名是否清晰？注释是否充分？
3. **性能**：是否有不必要的循环或重复计算？
4. **安全性**：是否有输入验证？是否有注入风险？
5. **可维护性**：函数是否过长？职责是否单一？
